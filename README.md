# FLAN_PACT — версия от 21 октября 2026 года

Готовые статические файлы PWA для GitHub Pages. Сборка и установка зависимостей не требуются.

## Обновление существующего сайта

1. Распакуйте архив.
2. Загрузите содержимое этой папки в папку репозитория, из которой уже публикуется сайт. Файл index.html должен находиться на том же уровне, что и раньше, без дополнительной вложенной папки.
3. Замените одноимённые файлы, включая папки icons и fonts.
4. Сохраните существующий файл CNAME и настройки публикации вашего домена. В архиве CNAME намеренно отсутствует.
5. Сохраните изменения в репозитории и дождитесь окончания публикации.
6. Обновите приложение. Если открыта старая версия, закройте вкладки приложения и откройте его снова.

## Страницы

- index.html — приложение.
- demo.html — просмотр десктопной и мобильной версий рядом. После публикации откройте адрес вашего сайта с /demo.html в конце.

## Данные

Архив содержит код и ресурсы приложения, без ваших задач и заметок из хранилища браузера. Перед обновлением можно экспортировать данные через настройки приложения. Не очищайте данные сайта для обновления версии.

GitHub Pages размещает статическое приложение. Сервер синхронизации и фоновых push-уведомлений в этот пакет не входит; для этих функций требуется отдельно работающий сервер.
